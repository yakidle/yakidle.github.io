同步到 yakidle.github.io 的步骤

管理页的增删改先保存到你电脑上的 docs/story-archive/。电脑上的故事列表立即更新。

  1. 打开 GitHub Desktop 中的「小鱼爱可可」仓库。
  2. 确认新增/删除的录音和 catalog.json 变化。
  3. Commit，再 Push origin。
  4. GitHub Pages 发布完成后，公网故事库自动同步；即使电脑关机，真人录音仍可播放。

PRIVATE KEYS

给可可的听故事暗号

管理员密钥只给你本人使用。听故事暗号可以单独告诉可可，用于「我想听这个」的声音合成。暗号保存在电脑本地配置里，不应上传 GitHub。

管理员密钥：settings.local.json 里的 admin_key
可可的暗号：settings.local.json 里的 listener_key

如果想更换暗号，修改本地配置并重启网站服务即可。为防止别人无限占用你的 GPU，服务器还会对请求频率作限制。
