# 可可爱拼豆 🧡

> 给可可的一份小礼物，把喜欢的图片，一颗一颗拼出来。

这是我为女朋友 **可可** 做的拼豆图纸小工具。

希望她想拼一张喜欢的图片时，能少花一点时间整理格子、配色和数豆子，多留一点时间享受亲手完成作品的过程。

可可，你负责挑喜欢的图，格子和颜色就交给这个小工具。

## 关于这个工具

将普通图片转换为拼豆图纸的网页工具。支持调节图纸分辨率、切换品牌色卡、合并相近颜色，并导出图纸和材料用量表。

所有图片均在浏览器本地处理，无需上传到服务器。

## 功能

- **图像调节**：调节亮度、对比度、饱和度、色调和色温，支持调整前后对照及一键重置。
- **自定义分辨率**：长边支持 8–300 颗豆子，另一边按图片比例自动计算。
- **平均池化**：计算每个网格区域的平均颜色，再匹配所选色卡中的真实色号。
- **限制颜色数量**：保持分辨率不变，优先融合最相近的颜色，减少所需颜色种类。
- **外围白底留空**：识别与图片边缘连通的白色背景，保留封闭区域内的白色。
- **图纸预览**：支持原图、纯色块预览和带坐标、色号的图纸视图。
- **用量统计**：统计各色号所需豆子数量，点击颜色可高亮对应位置。

无法确认的色号及数据中明确标记为透明的颜色，不参与自动匹配。具体可用色数以页面显示为准。

## 使用方法

1. 用浏览器打开 `index.html`。
2. 上传或拖入图片，也可以先使用内置示例。
3. 按需调整图像颜色，再调整长边豆子数量，选择实际使用的品牌色卡。
4. 如需减少用色，打开“限制用色数量”并设置上限。
5. 根据需要调整白底识别设置。
6. 下载预览图、色号图纸或颜色用量表。

支持 JPG、PNG、WebP 和 AVIF，图片最大 30 MB、1600 万像素。

## 导出内容

- **色块预览 PNG**：不带网格和色号，空白区域透明。
- **色号图纸 PNG**：包含网格、四边坐标、格内色号及用量图例。
- **颜色用量表 PNG**：展示各颜色和所需豆子数量。
- **颜色用量表 CSV**：方便进一步整理或采购。

## 图像调节

支持亮度、对比度、饱和度、色调与色温五项调节：

| 参数 | 范围 | 用途 |
| --- | --- | --- |
| 亮度 | -100 至 +100 | 调暗或提亮图像 |
| 对比度 | -100 至 +100 | 调整明暗差异 |
| 饱和度 | -100 至 +100 | 从黑白到更鲜艳的颜色 |
| 色调 | -180° 至 +180° | 沿色环旋转色相 |
| 色温 | -100 至 +100 | 负值偏冷，正值偏暖 |

所有参数默认 0。可在“原图”和“调整后”视图间切换对照，点击“重置全部”恢复默认。上传新图片时自动重置图像调节参数。

调节作用于原始像素，之后再平均池化、匹配色卡和合并颜色，所有图纸与用量导出同步使用调整后的结果。每次从原图重新计算，避免反复调节产生累积失真。

背景识别依据原图，已识别的外围白底及透明区域不会因调色变成需放豆子的格子。

## 分辨率与颜色数量

这两个参数可以分别调节：

- **豆子数量越多**：图纸格子越多，细节更丰富，成品尺寸也越大。
- **颜色数量越少**：相近颜色合并，所需颜色种类减少，图纸格数保持不变。

颜色数量设置的是上限。如果原图实际用色少于上限，不会额外增加颜色。

## 处理原理

1. 从图片边缘识别连通的近白背景，生成留空区域。
2. 根据图像调节参数处理原始像素，再均匀划分为网格，按像素覆盖面积计算各格的 RGB 均值。
3. 将平均颜色匹配到所选色卡中最接近的颜色。
4. 开启颜色限制时，按 CIELAB 颜色距离逐步合并最相近的颜色组，并为每组保留一个真实色号。
5. 生成图纸并统计豆子用量。

白底参与平均池化；背景识别用于判断格子是否留空。默认主体覆盖至少一格的 50% 才放置豆子，此比例可调整。

## 部署到 GitHub Pages

将 `index.html` 放在仓库根目录，然后设置：

**Settings → Pages → Deploy from a branch → main → /(root) → Save**

发布完成后，即可通过 GitHub Pages 提供的网址使用。

## 使用提示

- 屏幕 RGB 仅作为颜色参考，实际豆子可能因批次、材质和显示设备产生色差。
- 购买豆子时，请核对品牌、系列及色号。
- 与外围白底直接相连的白色主体可能被一起留空，可降低白底容差、关闭留空，或使用透明背景图片。
- 成品尺寸根据所选豆子间距估算，实际尺寸可能受拼板及熨烫影响。
