【小鱼爱可可】快速开始

1. 下载并解压 ZIP，确认文件夹里有 docs、server、scripts、START_WINDOWS.bat。
2. 为了以后可以持续更新故事，请先用 GitHub Desktop 打开原仓库 yakidle/yakidle.github.io，把本项目的文件复制进该仓库目录。以后只从仓库目录启动项目，不要运行下载目录里的另一个副本。
3. 下载安装 GPT-SoVITS 官方 Windows 整合包（需要 api_v2.py、runtime\python.exe 和模型权重）。
4. 在 GitHub 仓库工作目录中，双击 START_WINDOWS.bat；首次输入 GPT-SoVITS 路径。
5. 在启动输出里找到两个密钥：admin_key（只给你自己）以及 listener_key（可以单独告诉可可）。
6. 打开 http://127.0.0.1:7865/admin/ ，使用 admin_key 登录。上传你的5–10秒声音参考录音和对应文字；录制/上传第一篇故事。
7. 本地打开 http://127.0.0.1:7865/ 查看整合后的网站。
8. 在仓库 Settings → Pages 设为 main /docs，然后 GitHub Desktop Commit + Push，更新 https://yakidle.github.io/ 。
9. 以后添加、修改或删除故事，再在 GitHub Desktop 提交并推送 docs/story-archive/ 的变化，GitHub Pages 会同步更新。真人故事发布后，即使电脑关机也能播放。
10. 要从网页调用本机 GPT-SoVITS，请使用 Cloudflare Tunnel 将公网 HTTPS 地址指向本机 7865。把地址填进 docs/site-config.js 的 apiBase 后推送。可可在“我想听这个”填写 listener_key 即可合成声音。

注意：模型、真人故事音频和你的声音均未包含在 ZIP 中。
settings.local.json、data/ 不能上传 GitHub；docs/story-archive/audio/ 中发布的故事录音是公开文件。
更详细的步骤见 README.md。
